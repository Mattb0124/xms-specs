## 1. Summary

The pilot-grade core of XMS exists as two deployables plus a web app, built security-first against the architecture and module specifications: forced row-level security per account, a permission-declared route table, append-only audit with tamper evidence, a transactional outbox, and every business rule in one TypeScript codebase shared by the API and the worker. The build followed the thirty-day plan day by day; the items below are what shipped, with the cuts and deviations stated where they were made.

Counts on 2026-09-08, after the PDF rendition and review-before-send work on report packs (DR-05): backend 226 unit and 54 end-to-end tests, and 937 integration tests, which is the whole `pnpm test:int` run and so includes the 642-assertion isolation suite; frontend 898 tests; 271 routes in the golden snapshot, three more than before for the three review routes; migrations 0001 to 0034. The 2026-09-08 security review is closed except for the items that belong to the web client or to `xms-infra`, and the resolution table names the commit that closed each one ([REVIEW-security-2026-09-08](./REVIEW-security-2026-09-08.md), Resolution).

## 5. Local run-through (2026-09-07)
